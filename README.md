# HealthForge

Self-contained weight-loss and wellness web app. Open `index.html` directly, or host the folder on any HTTPS site to install it on a phone (Add to Home Screen).

- Source lives in `src/` (styles, `js/` modules, `template.html`). Rebuild `index.html` with `python build.py`.
- Data is stored in the browser (localStorage). Use Settings > Backup to export and move data between devices.
- Before editing, snapshot the project into `backups/` with a timestamp (project rule).
